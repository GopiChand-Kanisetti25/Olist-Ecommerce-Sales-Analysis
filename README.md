# Olist E-Commerce Sales Analysis

## Project Overview
This project analyzes Brazilian e-commerce sales data from the Olist dataset to identify sales trends, customer behavior, product performance, payment preferences, and delivery performance.

## Tools & Technologies
- Python
- Pandas and NumPy
- MySQL
- Power BI
- Excel/CSV

## Key Business Questions
1. How does revenue change month by month?
2. Which product categories generate the highest revenue?
3. Which Brazilian states contribute the most revenue?
4. What payment methods do customers prefer?
5. What percentage of customers make repeat purchases?
6. How many orders are delivered on time versus late?

## Key Findings
- Total product revenue: approximately R$13.59 million.
- Total orders: approximately 96K.
- Total unique customers: approximately 96K.
- Health & Beauty and Watches & Gifts are among the top revenue-generating categories.
- São Paulo contributes the highest state revenue.
- Credit cards are the most commonly used payment method.
- Repeat customers represent a small proportion of customers.

## Project Structure
- Data: Raw and cleaned datasets
- Notebooks: Python analysis notebooks
- Python: Data cleaning and analysis scripts
- SQL: SQL queries
- Power BI: Interactive dashboard
- Reports: Project findings and documentation

## Dashboard
The Power BI dashboard presents monthly revenue, total orders, customer analysis, top product categories, state-wise revenue, payment methods, and delivery performance.

## Conclusion
The analysis provides insights into revenue trends, customer purchasing behavior, product performance, and delivery operations that can support better business decisions.

## Dataset
Olist Brazilian E-Commerce Public Dataset (Kaggle).
